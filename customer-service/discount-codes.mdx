Uncle J's periodically offers discount codes for Pitmaster Rewards members, email subscribers, and special occasions. Here's how they work.

---

## Applying a Discount Code

Discount codes are entered at checkout, just before payment. Look for the **"Have a promo code?"** field on the order summary step — enter your code there and click **Apply**.

If the code is valid, the discount will be reflected in your order total before you complete payment.

---

## Types of Discounts

| Type | How It Works |
|---|---|
| **Percentage off** | Takes a percentage off your eligible subtotal (e.g. 10% off) |
| **Fixed dollar amount** | Deducts a flat dollar amount from your subtotal (e.g. $5 off) |
| **Item-specific** | Applies only to certain menu items — other items are full price |

## Common Issues

**My code isn't working.**
A few things to check:
- Make sure the code is entered exactly as given — codes are case-sensitive
- Check the expiry date — many codes are time-limited
- Verify your order meets any minimum requirements (e.g. minimum subtotal)
- Some codes are restricted to specific items — if you don't have a qualifying item in your cart, the code won't apply

**Can I use two codes at once?**
No — only one discount code can be applied per order. Codes also cannot be stacked with Pitmaster Rewards redemptions at this time.

**My code expired. Can you extend it?**
Expired codes generally cannot be reactivated. [Contact us](https://links.unclebbq.com/contact) if you believe your code expired due to a technical issue and we'll look into it.

**I forgot to apply my code before paying.**
Unfortunately we cannot apply discount codes retroactively after an order is completed. Make sure to enter your code before clicking Pay.

---

## Restrictions

- Codes cannot be applied to catering orders over $250 (those go through a separate quoting process)
- Codes cannot be applied to delivery fees or taxes — only to the food subtotal
- Codes marked "one-time use" expire after their first successful redemption
